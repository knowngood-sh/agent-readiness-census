# Agent-Readiness Census

A monthly count of how much of the web actually implements the agent-ready
standards — measured, not estimated. Maintained by [knowngood.sh](https://knowngood.sh),
a search engine for AI agents that lists only probe-verified capabilities.

### The reading

**A two-tier world with a cliff.** The *declared* tier has gone mainstream:
llms.txt is on 1.9M domains (much of it auto-generated by SEO plugins and
site platforms) and agents.md is five figures. The *capability* tier — the
standards that let an agent actually discover and call an endpoint — is
double or triple digits. Eighty domains on the crawled web serve an MCP
server card. The entire capability frontier currently fits in a single
probe run.

**auth.md at 66 domains** roughly three months after the spec launched is a
measurable launch curve. We re-count monthly; September lands next.

### Consent, measured

From a robots.txt pilot sampled from the same snapshot (10,658 live robots
files):
explicit `ai-input=no` appears on **3 hosts (0.03%)**; `ai-input=yes` on 38;
Content-Signal on 279 (2.6% — a rate high enough above webmaster baseline
that CDN-managed robots.txt injection is the likely driver, so treat it as
CDN adoption, not intent). Explicit refusal is vanishingly rare — which
makes honouring it absolutely essentially free. knowngood's probe honours
`ai-input=no` unconditionally: such sites are never probed and never listed.

### Read the numbers honestly

**Every count is a floor.** The underlying crawler only fetched URLs it
discovered.
`llms.txt` gets linked and advertised; `/.well-known/*` files rarely do —
so cross-standard comparisons are biased in llms.txt's favour, and the
well-known counts under-count worst. Use these numbers for magnitude and
trend, never as market sizes. Where we can't attribute a signal (was it
authored by the site, or injected by a platform or CDN?), we say so and
publish nothing until a verification pass settles it.

## Check your own site

```bash
python3 check.py example.com
```

`check.py` (stdlib-only, no dependencies) probes one host for the signals
above and prints a scorecard using the same rubric knowngood uses in
production — see [RUBRIC.md](RUBRIC.md). It reads robots.txt first and
refuses to probe a site that declares `ai-input=no` (pass `--owner` if it's
your own site).

## Method

Counts are queries over the URL index of a web-scale crawl snapshot,
collapsed to registrable domains. The consent pilot samples robots.txt
captures from the same snapshot. The census adds no crawling of its own —
it counts what was already fetched. Our own verification probes
(which feed [knowngood.sh](https://knowngood.sh), not this census) identify
as `KnownGood-Verifier` with a contact URL and honour robots.txt and
`ai-input` declarations absolutely.
